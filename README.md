# Dev-Centr README template

Blank GitHub README layouts adapted from [othneildrew/Best-README-Template](https://github.com/othneildrew/Best-README-Template), with corrections for badge destinations, centered headers, and role-grouped **Built With**.

Agent rules: [dev-centr/agent-rules](https://github.com/dev-centr/agent-rules) → `general/readme-layout.md`.

## Files

| File | Use |
|------|-----|
| `BLANK_README.md` | Full / user-facing Markdown |
| `BLANK_README.simplified.md` | Internal / non-downstream Markdown |
| `BLANK_README.adoc` | Full AsciiDoc (GitHub HTML header + local AsciiDoc path) |
| `BLANK_README.simplified.adoc` | Simplified AsciiDoc |

## Usage

1. Copy the blank that matches format + tier into your repo as `README.md` or `README.adoc`.
2. Replace `OWNER`, `REPO`, `BRANCH`, title, description, contact, and stack.
3. Delete sections you do not need; do not leave empty Roadmap/Acknowledgments filler.
4. Fork this template repo into other orgs or your user account if you want org-local copies.
